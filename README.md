## ✨ Features

| Feature              | Description                                                   |
| -------------------- | ------------------------------------------------------------- |
| ⌨️ Typed Animation   | Animated typing effect on the hero section                    |
| 🔝 Scroll to Top     | Anchor that brings the user back to the top of the page       |
| 📱 Responsive Design | Layout adapts across mobile, tablet, and desktop screen sizes |
| 🎨 CSS Modules       | Scoped per-component stylesheets — no class name collisions   |

## 🚀 Quick Start

### Install

```bash
git clone https://github.com/Preslav977/portfolio.git
cd portfolio
npm install
```

### Run

```bash
npm run dev
```

> App runs on [http://localhost:5173](http://localhost:5173)

---

## 🏗️ Architecture

```
src/
  components/   # Hero, Projects, About, ScrollToTop
  styles/       # CSS Modules — one file per component
```

Static React SPA deployed on Vercel. No backend or environment variables required.
